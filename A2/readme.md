# HOW TO RUN THE CODE:

1. Open a terminal and navigate to the folder A2
2. Create virtual env
3. ```
   python -m venv .venv
   source .venv/bin/activate
   ```
4. Install requirements
```
pip install -r requirements.txt
```
5. Run:

```
   jupyter notebook --no-browser
   # OR
   jupyter notebook
```

  If `jupyter notebook --no-browser`
    3. Copy the link from the terminal below: "Jupyter Server 2.17.0 is running at:"
    4. Open the file final_results.ipynb
    5. Click the option to select a kernel
    6. Select the option "Existing kernel" and paste the link
    7. Now you can run the cells in the notebook final_results.ipynb

  If `jupyter notebook`
    3. Open the link given in the terminal
    4. On the Jupyter server, navigate to the file final_results.ipynb
    5. Run the cells
